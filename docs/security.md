# Security — Finance Close & Reconciliation Platform

- Keep source-system credentials and connection details outside source control.
- Use read-only credentials for reconciliation inputs whenever possible.
- Preserve original source values and store adjustments separately.
- Restrict approval actions to authorized finance reviewers.
- Record reviewer, rule, timestamp, and disposition for consequential resolutions.
- Protect financial and customer data through least-privilege access.
- Do not expose real employer, customer, contract, or transaction data in public examples.
- AI assistance must not have direct write access to accounting or source systems.

This public repository uses synthetic data only.
